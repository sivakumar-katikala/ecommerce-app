To fix this, stop the server and set these two environment variables in the same terminal window before running python app.py again: 

$env:MAIL_USERNAME = "your_own_gmail@gmail.com"
$env:MAIL_PASSWORD = "your16charapppassword"
python app.py

MAIL_USERNAME is your own sending account (like a store's "orders@" address), not any buyer's email. MAIL_PASSWORD must be a Gmail App Password (16 characters) — your normal Gmail login password will not work. Full steps are in the README "Email Setup" section.
